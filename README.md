# تبيان المفصّل

موقع عربي جميل ومتجاوب يعرض سور المفصّل من سورة ق (50) إلى الناس (114).

«فُضِّلتُ بالمُفصَّل» — قال ﷺ: «أُعطيتُ مكان التوراة السبع، وأُعطيتُ مكان الزبور المِئين، وأُعطيتُ مكان الإنجيل المثاني، وفُضِّلتُ بالمُفصَّل» رواه أحمد.

## الأقسام
- 🕌 طوال المفصّل: ق (50) → النبأ (78)
- 🕋 أوساط المفصّل: النازعات (79) → الضحى (93)
- 🌙 قصار المفصّل: الشرح (94) → الناس (114)

## النشر عبر GitHub Pages
1. ارفع `index.html` إلى مستودع جديد
2. من Settings → Pages → اختر Branch: main + root
3. رابط النشر سيكون: `https://USERNAME.github.io/REPO/`
